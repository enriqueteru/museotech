# Three.js en el tema Museotech

- Se añade `three` como dependencia npm del tema (`^0.186.1`, lockfile fijado en `0.186.1`).
- El tema queda marcado como privado para evitar publicar por accidente un paquete npm del theme.
- La dependencia no se encola globalmente ni añade peso a páginas que todavía no la usan.
- Verificado: import ES module de `three` (revision 186), `npm ls three --depth=0` y `npm audit --omit=dev` (0 vulnerabilidades reportadas).
