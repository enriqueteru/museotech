# Rediseño del archivo de colaboradores

- Simplificadas las tarjetas a logos enlazados, sin marco, fondo, flechas, nombres ni textos de acción.
- Se dio más presencia a las tarjetas: marco editorial, área de logo, nombre visible y acción para visitar el sitio, con estados hover y foco accesibles.
- Se conservan los logos, nombres, enlaces y datos disponibles desde WordPress; no se añaden datos ficticios.
- Se ajustaron dimensiones y movimiento para móvil y para preferencias de movimiento reducido.
